# Observed service routes

Observed in a real September 2026 cleanup. Interfaces vary by version, region, and account. These are navigation hints, not fixed selectors or guarantees. Verify current descriptions and account context. Do not assume historical toggle values. This list is not a coverage limit.

| Service | Route / distinction |
|---|---|
| DoorDash | Profile/account → Settings → Notifications. Order Updates separate from Store Offers, DoorDash Offers, Recommendations, Reminders, Product Updates & News. Each opened a Push sheet with Done. Email preferences opened a separate form. |
| Uber | Account → Manage Uber account → Privacy & Data → Communication Preferences. Bypassed an unscrollable main menu. Driver Call or chat separate from Marketing → Push / Email. Return and press Save Changes, then reopen. |
| Amazon iPhone | Account/person tab → gear → Notifications. Account and shipping, Deals and recommendations, Feedback separate. Deals contained Savings, Recommendations, New releases. Website email settings are separate. |
| Amazon web | Account → Communication preferences → Deals and recommendations. Benefits could remain on after other marketing was off. Edit → Email checkbox → Update. |
| Instagram web | Settings → Notifications → Push / Email. Long per-category radio list. Location likes differs from location-sharing safety reminders. Preserve direct messages. |
| Snapchat | Profile → gear → search Notifications. Categories include Message Reminders, AI suggestions, Promotions, friend suggestions, Spotlight/Discover, stories, separate SMS marketing. Bitmoji in Notifications is appearance, not marketing. |
| TikTok | Profile → menu → Settings and privacy → Notifications. Inspect Interactions, Messages, suggestions, LIVE, TikTok Shop, Other, email/SMS. Seller marketing had a separate master plus Chat messages and Emails. |
| X iPhone | Profile → Settings and privacy → Notifications → Preferences → Push. Website pushes did not determine these. Likes/Reposts open submenus; record audience selections. Recommendations, topics, broadcasts, contact-join have separate switches. |
| X web | Settings → Notifications → Preferences → Push / Email. Browser pushes may be off while phone categories are on. |
| Reddit web | Settings → Notifications. Category modal: All on / Inbox / All off, then Save. Announcements offered only All on/Inbox in the observed account; use Inbox without claiming fully off. Email is separate. |
| YouTube web | Settings → Notifications. Recommended videos and Promotional content and offerings separate from subscriptions, comments, mentions, own-content activity. Preserve chosen channel alerts. |
| Discord desktop | User Settings → Notifications → Overview / Email. Friends-online and anniversaries separate from messages/calls. Server/channel preferences require separate review. |
| AccuWeather | Menu → Settings → Manage Notifications. Government Alerts, Lightning, forecasts, Weather News separate. News children: Top Stories, Astronomy, Air Quality / Allergy, Sports. |
| Chipotle | Profile → Personal & Preferences → Subscriptions. Email/Mobile Updates visible; device notification permission was broad. Do not leave Rewards. Finer push control was not established. |
| Sincerely | Profile → gear. Broad Notifications switch and Letter Time. Finer controls not established; preserve wanted letters/replies. |
| Kraken | Required physical-phone Face ID/passcode in the observed run. Defer without weakening security. This does not prove every financial app is inaccessible. |
| Mac inventory | System Settings → Notifications. Allow notifications from iPhone inventories mirrored sources, not underlying phone categories. |

## Direct web entry points

Use one focused known-URL attempt, then verify. If it fails, navigate visible service settings instead of guessing many URLs.

- YouTube: `https://www.youtube.com/account_notifications`
- Instagram: `https://www.instagram.com/accounts/notifications/`
- X: `https://x.com/settings/notifications`
- Reddit: `https://www.reddit.com/settings/notifications`, `https://www.reddit.com/settings/emails`
- Facebook: `https://www.facebook.com/settings/?tab=notifications`
- Amazon: `https://www.amazon.com/gp/css/homepage.html`

Facebook masters can leave child-channel values displayed as on until collapse/reload. Verify the persisted master; do not accidentally re-enable children. Its Other notifications category described app/game requests, news, nearby restaurants, and offers in the observed interface—inspect current text before deciding.
